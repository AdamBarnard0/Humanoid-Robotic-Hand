# The Design of a Humanoid Hand

Final year project by **Adam Barnard**.

This repository contains the resources for the design, build and testing of a humanoid robotic hand: source code, component datasheets, CAD models, images and videos.

## Repository structure

| Folder | Contents |
| --- | --- |
| [`Code/`](Code) | Source code (firmware, control software, simulations) |
| [`Datasheets/`](Datasheets) | Datasheets for the components used (actuators, sensors, electronics) |
| [`CAD/`](CAD) | CAD models, assemblies, STL/STEP exports and drawings |
| [`Images/`](Images) | Photos, renders, diagrams and result figures |
| [`Videos/`](Videos) | Demonstration and testing videos (or links to them) |
